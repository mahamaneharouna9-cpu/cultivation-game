# CULTIVATION — Design Bible (Condensed)

> Full 19-part design doc archived in git history. This file is the working reference.

## Vision
3D isometric Xianxia cultivation action RPG. **Cultivation IS the game**: 16 realms × 9 stages,
jade-slip manuals, organic Dao growth, living sect, family lineage across generations.

## Core Pillars
1. **Cultivation is Everything** — realms fundamentally change gameplay.
2. **Sect Life is Your World** — politics, rivals, masters, tournaments, hierarchy.
3. **Your Dao, Your Path** — everything compounds: Dao, arts, body, alchemy, weapon.
4. **Tropes Done Right** — young masters, auctions, secret realms, tribulations, face-slapping.
5. **Living World** — rogues, ruins, beasts, kingdoms, demonic cultivators, higher realms.
6. **Legacy Through Blood** — Dao Companion, children, genetics, Lineage Mode (play as heir).

## Controls (KBM)
WASD move (camera-relative) · Space dodge · LMB combo / hold heavy · RMB block/parry ·
1–6 skills · F interact · Shift sprint · V lock-on · C cultivation · Tab inventory · M map ·
J journal · Z meditate · X beast command · G family · Q/E rotate camera · Wheel zoom.

## Combat Philosophy
Simple inputs, deep expression. Same buttons from Qi Sensing to Supreme Immortal —
**realm changes the scale**, from gritty punches to star-shattering law attacks.
Realm suppression: higher realms exert crushing aura pressure; punch up with trump cards.

## 16 Realms
Mortal: Qi Sensing, Qi Condensation, Foundation Establishment, Core Formation, Nascent Soul.
Earth Immortal: Spirit Severing, Dao Seeking, Void Refinement, Body Integration, Tribulation Transcendence.
True Immortal: True, Golden, Profound Immortal, Celestial Sovereign, Dao Ancestor, Supreme Immortal.

## Key Systems
- **Spirit roots**: Mortal → Mixed → Dual → Single → Heavenly → Mutant (Chaos/Void/Time…).
- **Physiques**: Nine Yang, Frozen Yin, Sword Bone, Poison Body, Primordial Chaos Body, 20+.
- **Manuals**: Mortal → Earth → Heaven → Saint → Emperor → Immortal → Primordial tiers.
- **Mastery**: Beginner → Small Success → Large Success → Perfection → Transcendence.
- **Dao**: Seed → Sprout → Tree → Fruit → Domain → Grand Dao → Heavenly Dao. Grows from actions.
- **Sect ranks**: Servant → Outer → Inner → Core → Personal → Elder → Peak Master → Grand Elder → Sect Master.
- **Starting sects**: Azure Cloud (sword), Crimson Phoenix (fire/alchemy), Iron Mountain (body),
  Jade Spirit (formations), Shadow Moon (dark), Thousand Beast (taming), Heavenly Dao (elite).
- **Family**: courtship → bond → dual cultivation → children (genetics) → raising → Lineage Mode.
- **Crafting**: alchemy (flame minigame, pill lightning), artifact refining + weapon spirits, formations, talismans.
- **World**: sect grounds → wilderness → mortal kingdoms → rival sects → danger zones → Immortal World.
- **Drama engines**: Face, Karma, inner demons, qi deviation, tribulations, NPC rival simulation,
  aging/lifespan, seclusion time-skips, sect building, reincarnation NG+.

## Story (5 Acts)
Prologue (mortal + entrance exam) → Act 1 Outer Sect → Act 2 Inner Sect (romance, betrayal) →
Act 3 Core/Elder (sect war, sever attachment) → Act 4 wandering (Grand Tribulation: ascend or die) →
Act 5 Immortal World (submit to Heaven or defy it).

## Art Direction
Semi-realistic painterly: Chinese ink-wash + modern 3D. Jade/azure/gold palette, sea of clouds,
floating islets, glowing formation runes. Guzheng/erhu/dizi score; war drums in combat.
